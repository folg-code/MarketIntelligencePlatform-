# Milestones

## Purpose

Store project-specific milestone definitions and milestone-level outcomes.

Use this directory for approved milestone scope, acceptance expectations,
dependencies, and milestone decisions. Current execution state belongs in
`planning/current.md`.

## Suggested Milestone Template

```md
# Milestone: Name

## Outcome

## Scope

### Included

### Excluded

## Acceptance Expectations

## Dependencies

## Risks

## Decisions

## Status
```
