# Waves

## Purpose

Store rolling-wave execution plans for the current milestone.

Use waves to plan near-term executable work. Do not create detailed speculative
plans for distant work.

Prefer vertical tracer bullets: thin end-to-end slices that can be integrated
and validated quickly. Avoid broad horizontal layer plans unless they are
genuinely required to enable the next vertical slice.

## Suggested Wave Template

```md
# Wave: Name

## Goal

## Selected Work

## Integration Points

## Expected Feedback

## Dependencies

## Parallelizable Work

## Blocked Work

## Routing

## Assumptions

## Review Notes
```
