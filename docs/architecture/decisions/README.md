# Architecture Decision Records

## Purpose

Store accepted project-specific architecture decisions.

Create ADR files only when a decision changes durable architecture truth or
records a meaningful trade-off that future agents and humans should preserve.

## Naming

Use:

```text
ADR-001-short-kebab-title.md
ADR-002-short-kebab-title.md
```

## Template

```md
# ADR-000: Title

## Status

Proposed | Accepted | Superseded

## Context

What problem or constraint required a decision?

## Decision

What was decided?

## Consequences

What trade-offs, constraints, or follow-up work result from this decision?

## References

Links to relevant product, architecture, domain, task, or evidence sources.
```
