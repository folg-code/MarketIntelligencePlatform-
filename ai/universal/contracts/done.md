# Contract: Definition Of Done

## Purpose

Define when work may be considered complete.

## Task-Level Done

Task-level work is done when:

- the delegated goal is satisfied,
- acceptance expectations are supported by evidence,
- required checks were executed or explicitly marked unavailable,
- blocking findings are resolved,
- unresolved limitations are reported,
- required durable documentation is current when durable truth changed.

## Lightweight Done

Lightweight work is done when:

- the requested local change is complete,
- relevant local checks were run when available,
- risk or missing evidence is honestly reported,
- no escalation trigger remains unresolved.

## Not Done

Work is not done when:

- required behavior is still ambiguous,
- evidence is missing but presented as verified,
- blocking review or validation findings remain,
- required approval has not been obtained,
- durable documentation is stale after a durable truth change.
